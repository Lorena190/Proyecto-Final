# Descripción y análisis de sistema de cámaras En Suba, Bilbao.

## Descripción del Proyecto 
En Suba Bilbao, se presenta inseguridad, en parte por la ausencia de camáras de seguridad
en la zona, por eso mediante este proyecto se pretende analizar un sistema de control de camáras.
